# Hero fluid cursor

This application includes the official React Bits Splash Cursor JavaScript/CSS component, retrieved from the React Bits registry. The component is licensed under MIT + Commons Clause. The wrapper mounts it within SurfaceNet’s specimen hero and Android download section. [Registry component](https://reactbits.dev/r/SplashCursor-JS-CSS.json) · [License](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md)

The website also uses the Web Animation API module from Anime.js for the cover, section headings and recorded inspection interactions. It loads from the same origin and honors reduced motion. [Anime.js WAAPI documentation](https://animejs.com/documentation/web-animation-api/)

SurfaceNet adapts the rolling link labels seen on Trionn and the image-led browsing in Studio Leichtfried's gallery. A pointer-controlled reflection on the cover takes its cue from the tactile interactions in Site of Sites' Material World collection. [Trionn](https://trionn.com/) · [Studio Leichtfried](https://leichtfried.com/) · [Material World](https://www.siteofsites.co/collections/material-world)

Run `npm ci` then `npm run build` from this directory to reproduce the JavaScript bundles in `../dist/vendor`. Run `npm run build:motion` to update only Anime.js.
